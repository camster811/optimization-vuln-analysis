# Baseline v3: bounded five-contract specification

Declared October 21, 2026, before v3 corpus evaluation. Method ID: `ghidra-library-contract-bounds-v3`. This is a post-hoc extension after inspection of Phase 9 and Checkpoint A, not a replacement for either.

The only engine extension is five library effects. Inherit the v2 interpreter, stack-array heuristic, native-store fallback, allocation-success/failure exploration, permission/lifetime checks, concrete acyclic path policy, limits, witness handling and deterministic CWE tie rule. No loops/solver, new stack-size inference, instruction decoding, alias engine or testcase-specific wrapper summaries are introduced. Application wrappers are traversed normally.

The pinned System V Linux x86-64 GCC target has 8-byte pointers/unsigned long and four-byte wchar_t; verify compiler predefined sizes before freezing. New prototypes use explicit `unsigned int *` wide elements (four bytes in the pinned Ghidra GCC language), never host-dependent `wchar_t` parsing. Signed wchar_t and unsigned int have identical stored 32-bit representations here. Keep the exact v2 limits (4096 byte object/string limits, 4096 steps, 64 paths, depth 8, 300-second worker timeout). Byte lengths must fit unsigned 64-bit arithmetic and those resource bounds.

| API | Signature/effects |
|---|---|
| wmemset | `(uint32_t *dest, uint32_t value, uint64_t count) -> dest`; check count*4 and the entire destination footprint before writes; store little-endian repeated low-32-bit values. Unknown value stays unknown; extent remains checkable. Zero count has no writes. |
| wcslen | `(const uint32_t *src) -> uint64_t`; scan known readable four-byte elements through a zero element, within max_string_bytes. Return element count, not bytes. Zero bytes inside a nonzero element do not terminate. |
| wcscpy | `(uint32_t *dest,const uint32_t *src) -> dest`; establish readable source including full terminator, reject overlapping source/destination, then check and copy (length+1)*4 bytes. |
| strcat | `(char *dest,const char *src) -> original dest`; establish readable destination prefix and source including terminators, reject overlap, check appended source+NUL at prefix length while retaining the original destination object identity. |
| wprintf | `(const uint32_t *format,...) -> unknown int`; support literal ASCII characters, `%%`, `%ls` (readable terminated wide argument), `%d`, `%u`, `%lc` (recovered integer argument). Reject other conversions, modifiers, widths/precision, positional/dynamic formats, `%n`, missing/unknown required arguments. No selected application-memory writes. |

Development format inventory is declared as the literals used in independent fixtures: `L"%ls"`, `L"%ls\n"`, `L"%d %u %lc %%\n"`, and rejection fixtures `L"%n"`, `L"%*ls"`, `L"%1$ls"`, `L"%f"`. These are development inputs, not application-name exceptions. Preserve the literal bytes and extracted development format census in fixture provenance. Compiled wide literals include trailing padding so the unchanged 16-byte unknown-data window does not cross an ELF section boundary; fixture-only padding does not alter the copied string or any research input. If Ghidra fails to recover varargs, record argument_recovery rather than ignoring conversions.

Reads require live heap allocations, live inferred stack objects, or exported static bytes. Unknown/unreadable sources and terminators abstain; do not fill missing bytes. Permission conflicts remain unknown, read-only writes stop, and dangling frames/freed objects are rejected. Copy/concatenation overflow witnesses require readable source and supported overlap semantics before a destination check. Resource-limit, unknown-contract-source, invalid-element-count and overlapping-string-copy failures are explicit abstentions. An established witness before a later unsupported effect remains a witness under the inherited rule; an unsupported/faulting earlier effect cannot establish a later witness.

Relift every available research observation using the unchanged public-only lifter with the new prototypes. No private labels/source/oracle paths enter the worker. Validate the v3 result schema directly and reuse v2 structural/evidence/bound semantics through a projection of method/schema identifiers and v3-only abstention reasons. No original validator is edited.

Freeze code/policy/schema, imported method hashes, environment, tests, compiled fixture evidence and deterministic observation schedule before corpus prediction. All 160 cells remain. Durable dispatch without a result is terminal failed, never retried. Store raw worker output, public inputs, IR, times, errors, contract events and hashes.

Use that identical v3 IR for two evaluator-only ablations: disable the four added memory/string effects, or disable added wide-output effects. Disabled contracts abstain; prototypes do not change. These ablations are not the old v2 lifter. Join original private truth and saved LLM results only after all new predictions are durable. Share the frozen family-bootstrap weights and denominators. Any corpus-motivated repair requires a new revision/run; do not tune v3 after seeing its corpus predictions.
